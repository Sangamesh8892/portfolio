User story

priority: highmodule: FIrequested by: business

Functional spec · draft

Purpose

Flag open customer invoices that are past their due date, once a day.

Business rules

Overdue means the due date is before today. Paid or cleared items are ignored.

Output

A list for the collections team, sorted by amount and days overdue.

Schedule

Runs automatically every morning before the team starts.

Technical spec · grounded

Design pattern KB

Daily background job, following the consultant playbook for FI reports.

Objects STD

ZCL_FI_OVERDUE_FLAG · ZI_OPEN_ITEMS

Data source ADT

Reads open items through the existing CDS view found in the live system.

Error handling

Empty result is a valid run; failures are logged for review.

zcl_fi_overdue_flag.abap

CLASS zcl_fi_overdue_flag DEFINITION PUBLIC FINAL.
PUBLIC SECTION.
METHODS run IMPORTING iv_key_date TYPE d.
ENDCLASS.
CLASS zcl_fi_overdue_flag IMPLEMENTATION.
METHOD run.
SELECT * FROM zi_open_items
WHERE due_date < @iv_key_date
INTO TABLE @DATA(lt_overdue).
" flag for collections follow-up
ENDMETHOD.
ENDCLASS.
